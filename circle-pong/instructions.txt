Create a standalone, fully functional circular pong game saved to circular-pong.html.

Requirements:
- Self-contained in a single HTML file containing all necessary HTML5 Canvas, CSS, and vanilla JavaScript.
- Circular boundary with a paddle curved along the perimeter, controlled via keyboard (Arrow keys / A and D) or mouse movement along the circle.
- Ball spawns at the center with a random initial trajectory, bounces off the curved paddle, and resets if it exits past the boundary.
- Simple score counter and game-over / restart state.
- A slider for ball speed
- A slider for paddle size
- A slider for circle size
- Bind the space bar to pause the game and restart the game. During pause the player needs to be able to adjust the sliders, press the space bar again to continue.
- Clean, readable code with no external dependencies or CDN links.
